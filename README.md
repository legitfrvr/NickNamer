# Nick Finder

A simple, fast multithreaded OSINT username availability checker across 160+ platforms.

## Features
- Multi-threaded scanning (8 threads)
- Bilingual interface (English / Russian)
- Subdomain DNS resolution checks
- Text-based profile validation to minimize false positives

## Requirements
- Python 3.8+
- `requests`

## Installation
```bash
pip install -r requirements.txt
```

## Usage
Run the script directly:
```bash
python main.py
```
Or double-click `start.bat` on Windows.
